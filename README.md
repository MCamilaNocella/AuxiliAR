AuxiliAR, Conectados por la Salud

Aplicación web que conecta voluntarios del área de salud que quieran ayudar a otras personas que lo necesitan, 
complementado con acceso a información y recursos de salud. 

Link: http://auxiliar.estudy.ar

(Terminada para el 14/10)

Información técnica: Desarrollada con Vite, React, TypeScript, Tailwind, Java, Spring Boot, Docker, 
PostgreSQL e integración de LLm con Nvidia.
